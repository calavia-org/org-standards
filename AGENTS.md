# org-standards — Agent Instructions

> **MANDATORY READ**: This repository is governed by [`~/Development/Github/AGENTS.md`](../AGENTS.md) (organization-wide rules). Per-repo rules below provide project-specific details but **cannot override** organization rules.

## Project Overview

Central repository for organization-wide development standards, harnesses, and governance rules for `calavia-org`.

## Repository Layout

```
.
├── github-harness/
│   └── AGENTS.md              # Organization-wide GitHub workflow rules (source of truth)
├── scripts/
│   ├── sync-to-local.sh       # Copy the org harness to a local workspace + verify references
│   └── verify-agents.sh       # Validate AGENTS.md files + manifest coverage
├── templates/
│   ├── AGENTS.md.template                # Skeleton for new per-repo AGENTS.md files
│   ├── .pre-commit-config.yaml.template  # Canonical pre-commit configuration
│   └── pr-check-and-test.yml.template    # Canonical reusable-CI caller for PR checks
├── manifest.md                # Registry of all organizational AGENTS.md files
└── README.md                  # This file
```

## Tech Stack

- **Language**: Bash (`scripts/`), Markdown (docs)
- **Hooks**: pre-commit — this repo dogfoods `templates/.pre-commit-config.yaml.template`
- **CI**: reusable workflows from `calavia-org/workflows-lib`

## Environment Setup

```bash
# Validate every AGENTS.md against the manifest
./scripts/verify-agents.sh ~/Development/Github

# Sync the org harness into a local workspace
./scripts/sync-to-local.sh ~/Development/Github
```

## Linting & Formatting

```bash
# Run all hooks (markdownlint, actionlint, yaml/json checks)
pre-commit run --all-files
```

## Testing

```bash
# AGENTS.md consistency + manifest coverage
./scripts/verify-agents.sh ~/Development/Github
```

## CI/CD

- **PR checks**: `.github/workflows/pr-check-and-test.yml` calls `calavia-org/workflows-lib/.github/workflows/pr-check-and-test.yml@v0`. Start from `templates/pr-check-and-test.yml.template`: the caller MUST grant `contents: write` (the reusable workflow's pre-release job requests it, and GitHub validates callee permissions against the caller at startup, so `contents: read` causes `startup_failure`), and MUST set `run-tox: false` unless the repo has a `tox.ini`.
- **Release**: none — this repo has no versioned artifact.

## Commits & Branches

- All commits follow [Conventional Commits](https://www.conventionalcommits.org/) (`chore:`, `docs:`, `feat:`, `fix:` …).
- Branches use conventional prefixes: `feat/`, `fix/`, `chore/`, `docs/`, `refactor/`, `ci/`.
- Never commit directly to `main`/`master` — every change goes through a PR (squash merge only).

## Gotchas & Special Cases

- `github-harness/AGENTS.md` is the **source of truth**; the copy at `~/Development/Github/AGENTS.md` is generated by `scripts/sync-to-local.sh`. Edit the harness here, then sync.
- `scripts/sync-to-local.sh` **overwrites** `~/Development/Github/AGENTS.md` verbatim.
- Every per-repo `AGENTS.md` MUST appear in `manifest.md` and carry the MANDATORY READ notice.
- `scripts/verify-agents.sh` treats `~/Development/Github/AGENTS.md` and `org-standards/github-harness/AGENTS.md` as base files and skips the notice check for them.
